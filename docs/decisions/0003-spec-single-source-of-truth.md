# 0003: spec.yaml is the single source of truth; derived values go to generated/

- **Status:** accepted · **Date:** 2026-10-19 · **Scope:** toolkit

## Decision
All variant parameters live in `variants/<id>/spec.yaml`, validated by `schemas/spec.schema.json` (versioned). Tools write derived results (e.g. a maximized height or the selected actuators) to `variants/<id>/generated/` with a "generated by" header. Generated files are committed so readers and agents don't need to re-run tools, but they're never hand-edited.

## Consequences
- (+) Parallel agents can't silently disagree about a dimension.
- (+) Re-running `oh` regenerates everything after a spec change.
- (−) Schema changes ripple. They need an ADR and a `schema_version` bump.
