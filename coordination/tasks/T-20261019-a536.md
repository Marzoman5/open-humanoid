## Goal
Make the concept engine's table pickup collision-aware and whole-body, report the reachable table-height range and the grasp-and-lift demand per candidate, and make the table height a parameter. From the R1 package (`variants/adam/reviews/R1-concept-2026-10-19.md`, `challenge-3-R1-package.md` row 5): "arm too short" for every candidate at 0.45 m, a 131x-stall spike at 0.40 m (the hand path through the table), nothing reachable above 0.35 m at 0.55 m. R5 (MUST): pick up a <= 150 g object from table height (provisional 0.40-0.45 m).

## Done when
- [x] Approach path avoids the table: Cartesian waypoints over the table edge, every robot geom >= 3 mm from the table top in every frame (independent distance test).
- [x] Whole-body reach: knee (to the concept's CAD knee limit), hip hinge, waist yaw, step-in (standing gap), COM inside the foot polygon in every frame; the limit that binds is named (arm reach / table collision / balance / leg joint range / path).
- [x] Reachable table-height range and demand per candidate (`python -m openhumanoid.concept.motions.pickup`), table height a parameter.
- [x] Tests (`tests/test_concept.py::test_pickup_*`) and docs (`docs/concept-engine.md`, section "Whole-body pickup planner").
- [x] Pickup case rerun for the two R1 concepts through the tool; outputs in `variants/adam/generated/concept/R1-P1*/pickup_range*.{json,md}`.
